# negative

Negative and conformance tests: input the implementation should reject, and
proof that it does.

Arrives in **G6 (weeks 10-11)**. Two parts — the upstream SPDM responder
validator, with a root cause recorded for every failure it reports, and a small
suite reproducing the *class* of published 2026 advisories.

The distinction is deliberate and is repeated wherever these results appear:
reproducing the class of a bug is not auditing an implementation for it.
